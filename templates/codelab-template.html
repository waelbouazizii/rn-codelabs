Cours — Titre de la notion

Objectif

Ceci est un modèle de codelab. Un panneau de cours présente une notion, la compare avec Jetpack Compose et Flutter, puis la vérifie par un quiz. Remplacez ce contenu par celui de la vraie session avant publication.

Avant la séance

Ouvrez Expo Go sur votre téléphone et lisez la version de SDK qu'il prend en charge. Elle doit correspondre au SDK utilisé sur cette page (SDK 57). Sur iPhone, seule la version de l'App Store fonctionne : en cas d'écart, attendez la mise à jour de la page au lieu d'installer une autre version d'Expo Go.

Compose, Flutter et React Native

Notion Jetpack Compose Flutter React Native
État local remember { mutableStateOf(0) } setState(() => count++) const [count, setCount] = useState(0)

Quiz éclair

Juste après l'appel setCount(count + 1) dans un gestionnaire onPress, que vaut count dans la suite de cette même fonction ?

setCount demande un nouveau rendu ; la variable count du rendu en cours ne change pas. La nouvelle valeur n'est visible qu'au rendu suivant, comme une nouvelle exécution de la fonction @Composable.

Score de la session : 0 / 0 (bonnes réponses au premier essai)

Objectif

Afficher un compteur sur le téléphone avec Expo Go et vérifier que Fast Refresh applique une modification sans relancer l'application.

Commandes

Bash et PowerShell (identique) :

npx expo start

Code complet

Fichier src/app/index.tsx :

import { useState } from 'react';
import { Pressable, StyleSheet, Text, View } from 'react-native';

export default function Index() {
  const [count, setCount] = useState<number>(0);

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Compteur : {count}</Text>
      <Pressable style={styles.button} onPress={() => setCount((c) => c + 1)}>
        <Text style={styles.buttonText}>Ajouter 1</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, alignItems: 'center', justifyContent: 'center', gap: 16 },
  title: { fontSize: 24, fontWeight: '600' },
  button: { backgroundColor: '#1f2430', paddingHorizontal: 20, paddingVertical: 12, borderRadius: 8 },
  buttonText: { color: '#ffffff', fontSize: 16 },
});

Résultat attendu

Le terminal affiche un QR code. Après le scan, le téléphone affiche « Compteur : 0 » et un bouton « Ajouter 1 ».

Vérification

  • Sur le téléphone, trois appuis sur « Ajouter 1 » affichent « Compteur : 3 ».
  • Après avoir remplacé « Compteur » par « Total » et enregistré, le téléphone affiche le nouveau texte sans redémarrer l'application.

À retenir

Pourquoi ? Un composant React est une fonction de ses props et de son état : chaque appel à setCount relance la fonction et produit une nouvelle interface, comme une recomposition en Compose ou un appel à build() en Flutter.
