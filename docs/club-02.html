Avant la séance

[SDK] Expo Go, installé depuis le store, fonctionne maintenant avec le SDK 58, et la séance 1 crée déjà un projet SDK 58. Cette page fonctionne sans changement sur les SDK 57 et 58.

  • Vous avez un projet club-tasks de la séance 1 : lancez npx expo start. S'il s'ouvre dans Expo Go, ne changez rien.
  • Expo Go indique que le projet n'est pas compatible avec sa version : mettez le projet à jour une seule fois avec les commandes ci-dessous, puis suivez la page normalement.
  • Nouvel étudiant, ou pas de projet : suivez « Point de départ » plus bas.
  • Expo Go affiche encore le SDK 57 : mettez-le à jour depuis le store (sur iPhone, seule la version du store fonctionne).

Seulement si Expo Go refuse le projet : mettre le projet à jour (Bash et PowerShell identique)

npx expo install expo@^58.0.0 --fix '--' --legacy-peer-deps
npx expo start --clear

Les guillemets autour de -- sont nécessaires dans PowerShell et acceptés par Bash. L'option --legacy-peer-deps évite un conflit de dépendances npm pendant la mise à jour.

Fichier src/app/index.tsx :

import { useState } from 'react';
import { FlatList, Pressable, StyleSheet, Text, TextInput, View } from 'react-native';
import TaskItem from '../components/TaskItem';
import Clock from '../components/Clock';

type Task = { id: string; title: string; done: boolean };

const INITIAL_TASKS: Task[] = [
  { id: '1', title: 'Installer Node.js', done: true },
  { id: '2', title: 'Créer le projet Expo', done: true },
  { id: '3', title: 'Comprendre useState', done: false },
];

export default function Index() {
  const [tasks, setTasks] = useState<Task[]>(INITIAL_TASKS);
  const [text, setText] = useState('');

  const remaining = tasks.filter((t) => !t.done).length;

  function addTask() {
    const title = text.trim();
    if (title === '') return;
    setTasks([...tasks, { id: Date.now().toString(), title, done: false }]);
    setText('');
  }

  function toggleTask(id: string) {
    setTasks(tasks.map((t) => (t.id === id ? { ...t, done: !t.done } : t)));
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Club Tasks</Text>
      <Clock />
      <Text style={styles.subtitle}>{remaining} tâche(s) restante(s)</Text>

      <View style={styles.inputRow}>
        <TextInput
          style={styles.input}
          value={text}
          onChangeText={setText}
          placeholder="Nouvelle tâche"
          onSubmitEditing={addTask}
        />
        <Pressable style={styles.button} onPress={addTask}>
          <Text style={styles.buttonText}>Ajouter</Text>
        </Pressable>
      </View>

      <FlatList
        data={tasks}
        keyExtractor={(t) => t.id}
        contentContainerStyle={styles.list}
        renderItem={({ item }) => (
          <TaskItem title={item.title} done={item.done} onToggle={() => toggleTask(item.id)} />
        )}
      />
    </View>
  );
}

import { useEffect, useState } from 'react';
import { StyleSheet, Text } from 'react-native';

export default function Clock() {
  const [now, setNow] = useState(new Date());

  useEffect(() => {
    const id = setInterval(() => setNow(new Date()), 1000);
    return () => clearInterval(id);
  }, []);

  return <Text style={styles.clock}>{now.toLocaleTimeString('fr-FR')}</Text>;
}

const styles = StyleSheet.create({
  clock: { fontSize: 14, color: '#868e96' },
});

Résultat attendu

L'écran de la liste a une barre de titre « Club Tasks » ; chaque tâche a un lien bleu « Détails ». Un appui sur « Détails » ouvre l'écran « Tâche n° 1 », avec une flèche de retour dans la barre de titre.

Vérification

  • Un appui sur la ligne d'une tâche la barre toujours.
  • « Détails » ouvre l'écran de la bonne tâche : le numéro affiché correspond à la ligne.
  • La flèche de retour de la barre de titre, ou le geste retour d'Android, ramène à la liste.

À retenir

Pourquoi ? Link change l'adresse et Expo Router trouve le fichier correspondant. La pile garde la liste en dessous : le retour est immédiat et la liste retrouve son état.

Le problème

L'écran de détail reçoit seulement l'identifiant. La liste est dans l'état de index.tsx, que cet écran ne peut pas lire. L'Étape 2 règle ce problème.

Erreurs fréquentes

  • Un écran « route introuvable » signifie que le fichier n'est pas exactement src/app/task/[id].tsx, crochets compris.
  • Si « Détails » ne fait rien, l'attribut href du lien contient une faute de frappe.
  • VS Code propose parfois un import automatique du type 'src/...' : remplacez-le par le chemin relatif indiqué.

Code complet

Qu'est-ce qu'un Context ?

Un Context est une boîte placée au-dessus de tous les écrans : n'importe quel écran l'ouvre avec un hook. Chez Flutter, c'est le rôle de Provider ; avec Compose, de CompositionLocal ou d'un ViewModel partagé.

Nouveau fichier src/context/TasksContext.tsx :

import { createContext, useContext, useState, type ReactNode } from 'react';

export type Task = { id: string; title: string; done: boolean };

type TasksContextValue = {
  tasks: Task[];
  addTask: (title: string) => void;
  toggleTask: (id: string) => void;
};

const INITIAL_TASKS: Task[] = [
  { id: '1', title: 'Installer Node.js', done: true },
  { id: '2', title: 'Créer le projet Expo', done: true },
  { id: '3', title: 'Comprendre useState', done: false },
];

const TasksContext = createContext<TasksContextValue | null>(null);

export function TasksProvider({ children }: { children: ReactNode }) {
  const [tasks, setTasks] = useState<Task[]>(INITIAL_TASKS);

  function addTask(title: string) {
    setTasks((current) => [...current, { id: Date.now().toString(), title, done: false }]);
  }

  function toggleTask(id: string) {
    setTasks((current) => current.map((t) => (t.id === id ? { ...t, done: !t.done } : t)));
  }

  return (
    <TasksContext.Provider value={{ tasks, addTask, toggleTask }}>{children}</TasksContext.Provider>
  );
}

export function useTasks(): TasksContextValue {
  const value = useContext(TasksContext);
  if (value === null) {
    throw new Error('useTasks must be used inside TasksProvider');
  }
  return value;
}

Objectif

Comprendre Promise, async/await et les trois états d'une requête.

Attendre sans bloquer

Une requête réseau prend du temps et l'application ne doit pas se figer. fetch renvoie une Promise : une valeur qui arrivera plus tard.

Exemple à lire

async function loadTitle(): Promise<string> {
  const response = await fetch('https://jsonplaceholder.typicode.com/todos/1');
  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`);
  }
  const todo: { title: string } = await response.json();
  return todo.title;
}
Mot Rôle
async marque une fonction qui peut attendre ; elle renvoie toujours une Promise.
await met la fonction en pause jusqu'à l'arrivée de la valeur, sans bloquer l'application.
response.ok vaut vrai pour un code HTTP de 200 à 299 ; fetch n'échoue pas pour un code 404 ou 500.
throw et try...catch throw lance une erreur ; catch la récupère pour afficher un message au lieu de planter.

import { createContext, useContext, useState, type ReactNode } from 'react';

export type Task = { id: string; title: string; done: boolean };

type TasksContextValue = {
  tasks: Task[];
  addTask: (title: string) => void;
  toggleTask: (id: string) => void;
  importTasks: (newTasks: Task[]) => void;
};

const INITIAL_TASKS: Task[] = [
  { id: '1', title: 'Installer Node.js', done: true },
  { id: '2', title: 'Créer le projet Expo', done: true },
  { id: '3', title: 'Comprendre useState', done: false },
];

const TasksContext = createContext<TasksContextValue | null>(null);

export function TasksProvider({ children }: { children: ReactNode }) {
  const [tasks, setTasks] = useState<Task[]>(INITIAL_TASKS);

  function addTask(title: string) {
    setTasks((current) => [...current, { id: Date.now().toString(), title, done: false }]);
  }

  function toggleTask(id: string) {
    setTasks((current) => current.map((t) => (t.id === id ? { ...t, done: !t.done } : t)));
  }

  function importTasks(newTasks: Task[]) {
    setTasks((current) => [
      ...current,
      ...newTasks.filter((task) => !current.some((t) => t.id === task.id)),
    ]);
  }

  return (
    <TasksContext.Provider value={{ tasks, addTask, toggleTask, importTasks }}>
      {children}
    </TasksContext.Provider>
  );
}

export function useTasks(): TasksContextValue {
  const value = useContext(TasksContext);
  if (value === null) {
    throw new Error('useTasks must be used inside TasksProvider');
  }
  return value;
}

import AsyncStorage from '@react-native-async-storage/async-storage';
import { createContext, useContext, useEffect, useState, type ReactNode } from 'react';

export type Task = { id: string; title: string; done: boolean };

type TasksContextValue = {
  tasks: Task[];
  addTask: (title: string) => void;
  toggleTask: (id: string) => void;
  importTasks: (newTasks: Task[]) => void;
};

const INITIAL_TASKS: Task[] = [
  { id: '1', title: 'Installer Node.js', done: true },
  { id: '2', title: 'Créer le projet Expo', done: true },
  { id: '3', title: 'Comprendre useState', done: false },
];

const STORAGE_KEY = 'club-tasks';

const TasksContext = createContext<TasksContextValue | null>(null);

export function TasksProvider({ children }: { children: ReactNode }) {
  const [tasks, setTasks] = useState<Task[]>(INITIAL_TASKS);
  const [loaded, setLoaded] = useState(false);

  useEffect(() => {
    async function load() {
      try {
        const json = await AsyncStorage.getItem(STORAGE_KEY);
        if (json !== null) {
          setTasks(JSON.parse(json) as Task[]);
        }
      } catch (error) {
        console.warn('Lecture impossible', error);
      } finally {
        setLoaded(true);
      }
    }
    load();
  }, []);

  useEffect(() => {
    if (!loaded) return;
    AsyncStorage.setItem(STORAGE_KEY, JSON.stringify(tasks)).catch((error) => {
      console.warn('Sauvegarde impossible', error);
    });
  }, [tasks, loaded]);

  function addTask(title: string) {
    setTasks((current) => [...current, { id: Date.now().toString(), title, done: false }]);
  }

  function toggleTask(id: string) {
    setTasks((current) => current.map((t) => (t.id === id ? { ...t, done: !t.done } : t)));
  }

  function importTasks(newTasks: Task[]) {
    setTasks((current) => [
      ...current,
      ...newTasks.filter((task) => !current.some((t) => t.id === task.id)),
    ]);
  }

  return (
    <TasksContext.Provider value={{ tasks, addTask, toggleTask, importTasks }}>
      {children}
    </TasksContext.Provider>
  );
}

export function useTasks(): TasksContextValue {
  const value = useContext(TasksContext);
  if (value === null) {
    throw new Error('useTasks must be used inside TasksProvider');
  }
  return value;
}
