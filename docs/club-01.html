Objectif

Savoir à quoi servent React, React Native, Expo et Expo Go.

React : décrire l'interface

React (2013, Facebook) est déclaratif : vous décrivez ce que l'écran affiche pour un état donné, et React le met à jour.

Composants

Une application est un arbre de composants : chaque composant en contient d'autres, jusqu'aux plus petits éléments de l'écran.

React Native, Expo et Expo Go

  • React Native transforme <View> et <Text> en vues natives.
  • Expo est la boîte à outils : création du projet, serveur de développement, bibliothèques.
  • Expo Go est une application sur le téléphone qui exécute votre projet après le scan d'un QR code : Android Studio n'est pas nécessaire.

Expo Go contient un ensemble fixe de modules natifs. Une bibliothèque qui apporte son propre code natif demande un development build, que cette formation n'utilise pas.

Notion Ce que fait le code
const et let const crée une variable qu'on ne réaffecte pas ; let crée une variable qu'on peut réaffecter, comme year.
Fonction fléchée et gabarit de texte (n: string): string => est une fonction courte. Entre accents graves, ${n} insère une valeur dans le texte.
Déstructuration const { year: currentYear } = student lit la propriété year de l'objet et la range dans la variable currentYear.
Spread { ...student, year: 3 } crée un nouvel objet : il copie student, puis remplace year. L'original ne change pas.
map scores.map transforme chaque élément et renvoie une nouvelle liste : [13, 16, 10].
filter scores.filter garde les éléments qui passent le test et renvoie une nouvelle liste : [12, 15].
type et export type décrit la forme d'un objet ; export le rend utilisable depuis un autre fichier.

Code complet

import { useState } from 'react';
import { FlatList, Pressable, StyleSheet, Text, TextInput, View } from 'react-native';
import TaskItem from '../components/TaskItem';

type Task = { id: string; title: string; done: boolean };

const INITIAL_TASKS: Task[] = [
  { id: '1', title: 'Installer Node.js', done: true },
  { id: '2', title: 'Créer le projet Expo', done: true },
  { id: '3', title: 'Comprendre useState', done: false },
];

export default function Index() {
  const [tasks, setTasks] = useState<Task[]>(INITIAL_TASKS);
  const [text, setText] = useState('');

  const remaining = tasks.filter((t) => !t.done).length;

  function addTask() {
    const title = text.trim();
    if (title === '') return;
    setTasks([...tasks, { id: Date.now().toString(), title, done: false }]);
    setText('');
  }

  function toggleTask(id: string) {
    setTasks(tasks.map((t) => (t.id === id ? { ...t, done: !t.done } : t)));
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Club Tasks</Text>
      <Text style={styles.subtitle}>{remaining} tâche(s) restante(s)</Text>

      <View style={styles.inputRow}>
        <TextInput
          style={styles.input}
          value={text}
          onChangeText={setText}
          placeholder="Nouvelle tâche"
          onSubmitEditing={addTask}
        />
        <Pressable style={styles.button} onPress={addTask}>
          <Text style={styles.buttonText}>Ajouter</Text>
        </Pressable>
      </View>

      <FlatList
        data={tasks}
        keyExtractor={(t) => t.id}
        contentContainerStyle={styles.list}
        renderItem={({ item }) => (
          <TaskItem title={item.title} done={item.done} onToggle={() => toggleTask(item.id)} />
        )}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 24, gap: 12, backgroundColor: '#ffffff' },
  title: { fontSize: 28, fontWeight: '700' },
  subtitle: { fontSize: 16, color: '#495057' },
  inputRow: { flexDirection: 'row', gap: 8 },
  input: { flex: 1, borderWidth: 1, borderColor: '#ced4da', borderRadius: 8, paddingHorizontal: 12, paddingVertical: 10 },
  button: { backgroundColor: '#1f2430', paddingHorizontal: 16, justifyContent: 'center', borderRadius: 8 },
  buttonText: { color: '#ffffff', fontSize: 16, fontWeight: '600' },
  list: { gap: 8 },
});

Résultat attendu

  • Un champ vide n'ajoute rien.

À retenir

Pourquoi ? Le champ est contrôlé : value et onChangeText le lient à l'état. On ne modifie jamais l'état directement : [...tasks, newTask] et map créent de nouveaux tableaux, et React voit le changement. remaining est calculé à partir de tasks, pas stocké dans un autre état, et FlatList a besoin d'une clé stable par élément.

Erreurs fréquentes

  • Encountered two children with the same key signifie que keyExtractor renvoie deux fois la même valeur.
  • L'écran ne se met pas à jour après tasks.push(newTask) : le tableau reste le même objet.

import { useEffect, useState } from 'react';
import { StyleSheet, Text } from 'react-native';

export default function Clock() {
  const [now, setNow] = useState(new Date());

  useEffect(() => {
    const id = setInterval(() => setNow(new Date()), 1000);
    return () => clearInterval(id);

  return <Text style={styles.clock}>{now.toLocaleTimeString('fr-FR')}</Text>;
}

import { useState } from 'react';
import { FlatList, Pressable, StyleSheet, Text, TextInput, View } from 'react-native';
import TaskItem from '../components/TaskItem';
import Clock from '../components/Clock';

type Task = { id: string; title: string; done: boolean };

const INITIAL_TASKS: Task[] = [
  { id: '1', title: 'Installer Node.js', done: true },
  { id: '2', title: 'Créer le projet Expo', done: true },
  { id: '3', title: 'Comprendre useState', done: false },
];

export default function Index() {
  const [tasks, setTasks] = useState<Task[]>(INITIAL_TASKS);
  const [text, setText] = useState('');

  const remaining = tasks.filter((t) => !t.done).length;

  function addTask() {
    const title = text.trim();
    if (title === '') return;
    setTasks([...tasks, { id: Date.now().toString(), title, done: false }]);
    setText('');
  }

  function toggleTask(id: string) {
    setTasks(tasks.map((t) => (t.id === id ? { ...t, done: !t.done } : t)));
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Club Tasks</Text>
      <Clock />
      <Text style={styles.subtitle}>{remaining} tâche(s) restante(s)</Text>

      <View style={styles.inputRow}>
        <TextInput
          style={styles.input}
          value={text}
          onChangeText={setText}
          placeholder="Nouvelle tâche"
          onSubmitEditing={addTask}
        />
        <Pressable style={styles.button} onPress={addTask}>
          <Text style={styles.buttonText}>Ajouter</Text>
        </Pressable>
      </View>

      <FlatList
        data={tasks}
        keyExtractor={(t) => t.id}
        contentContainerStyle={styles.list}
        renderItem={({ item }) => (
          <TaskItem title={item.title} done={item.done} onToggle={() => toggleTask(item.id)} />
        )}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 24, gap: 12, backgroundColor: '#ffffff' },
  title: { fontSize: 28, fontWeight: '700' },
  subtitle: { fontSize: 16, color: '#495057' },
  inputRow: { flexDirection: 'row', gap: 8 },
  input: { flex: 1, borderWidth: 1, borderColor: '#ced4da', borderRadius: 8, paddingHorizontal: 12, paddingVertical: 10 },
  button: { backgroundColor: '#1f2430', paddingHorizontal: 16, justifyContent: 'center', borderRadius: 8 },
  buttonText: { color: '#ffffff', fontSize: 16, fontWeight: '600' },
  list: { gap: 8 },
});

À retenir

Pourquoi ? useEffect exécute du code en dehors du rendu (minuteurs, réseau, abonnements). Avec [], il s'exécute une seule fois, après le premier rendu. La fonction renvoyée est le nettoyage : elle s'exécute quand le composant disparaît, sinon le minuteur continuerait de tourner.

Erreurs fréquentes

  • Oublier le nettoyage laisse des minuteurs tourner en arrière-plan.
  • Un setState dans un useEffect sans tableau de dépendances provoque une boucle de rendus infinie.
